
# 🍕 Domino's Meal Planner  
*A simple way to plan your perfect Domino's meal within budget.*

---

## Key Features  
- **Budget-Based Meal Combinations**: Input your budget to see all possible meal combinations.  
- **Real-Time GST Calculation**: Automatically includes 18% GST on your total.  
- **User-Friendly UI**: Built with Jetpack Compose for smooth, modern interactions.  

---

## 🛠️ Tech Used  
- **Kotlin**: Primary programming language.  
- **Jetpack Compose**: Modern UI framework for Android.  
- **Android Studio**: Development environment.  

---

## 🚀 Usage  
```bash
# 1. Clone the Repository
git clone https://github.com/aditya13504/Dominos_Meal_Planner_App.git

# 2. Open in Android Studio  
- Import the project and wait for Gradle to sync.  

# 3. Run the App  
- Connect an Android device or use an emulator.  
- Click the "Run" button to launch the app.  
```

## How to Use
```bash
1. Enter Your Budget.

2. Browse Combinations:
   - Scroll through the list of meal combinations shown in the app.
   - Each combination includes item names, prices, and total cost.

4. View Totals:
   - Each combination shows:
     - Subtotal (before GST)
     - Calculated GST (18%)
     - Grand Total (subtotal + GST)
